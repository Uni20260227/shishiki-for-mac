# 歯式forMac

Excel・Word・PowerPoint・Numbers・Pages・Keynote に、十字（パーマー方式）の歯式を1行で入れるためのツールです。

- 紹介ページ・今すぐ使う：https://uni20260227.github.io/shishiki-for-mac/
