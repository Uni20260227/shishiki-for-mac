Features

Pick the teeth, copy, paste.

Palmer cross on one line

A dedicated font draws upper teeth, lower teeth and the cross lines in a single line of text. Works in Excel, Word, PowerPoint, Numbers, Pages and Keynote.

Marks and primary teeth

Primary teeth (A–E), circles (e.g. bridge abutments), double circles, triangles and more. Add a label such as Br or Crown in front.

Free and simple

Nothing to install except the font. It runs in your browser, and what you enter is never sent anywhere.

How to use

Install the font once, then it's three steps.

1

Install the font (once)

Double-click "ShishikiCross.ttf" in the zip and click "Install Font". Quit and reopen the app you paste into.

2

Pick teeth and copy

Click "Use it now", choose a mark, click the teeth, then "Copy". Offline? Open "歯式forMac.html" from the zip.

3

Paste

Excel and Word: just paste. PowerPoint, Keynote, Pages, Numbers: select the pasted text and set the font to ShishikiCross.

FAQ

I see boxes or Latin letters instead of the notation

The ShishikiCross font isn't installed, or the cell uses another font. Install the font and restart Excel, or set the cell's font to ShishikiCross.

PowerPoint, Keynote, Pages or Numbers show Latin letters

These apps drop the font when you paste. Select the pasted text and change the font to "ShishikiCross". You can also set an empty text box to ShishikiCross first and use "Paste and Match Style".

The formula bar shows other characters

The formula bar doesn't use the special font, so it shows other characters. The cell itself shows the notation correctly.

Can I use it offline?

Yes. Open "歯式forMac.html" from the zip. It works the same without an internet connection.

The file looks broken on another computer

That computer needs the font too. Share ShishikiCross.ttf together with the Excel file.

Can I use it without the font?

Yes. Switch the format to "Excel 2 lines" or "Text 1 line". It looks simpler than the special font, but needs nothing installed.

Does it work on Windows or iPad?

It has been tested on Mac only. The font is built to work on Windows as well (right-click the .ttf and choose "Install"). On iPad, installing a font needs a separate app. If you try it, please share the result on the feedback board.

Does it support FDI or Universal numbering?

Not yet. This version is for Palmer (Zsigmondy) notation. Let us know on the feedback board if you need it.
